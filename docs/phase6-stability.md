# Phase 6 reliability

- Wi-Fi join now snapshots enabled profiles, waits up to 15 seconds for the requested profile ID to reach COMPLETED, then restores prior enabled profiles before saving. Wrong passwords and stale associations do not save the new profile; a failed join removes the temporary profile and requests reconnection to prior enabled networks. An interrupted process is still a physical-test case. Association does not prove DHCP or internet connectivity.
- The UI shows installed and staged sequences separately; low-battery firmware downloads are rejected before payload transfer, with the existing independent battery check before recovery.
- The single-confirmation installer preserves signature and partition checks and uses the original recovery. Progress before reboot is preparation progress, not NAND-write progress.
- Test on the R1: successful and failed Wi-Fi passwords, network switching, DHCP renewal, reconnect after reboot and sleep; then one full Wi-Fi firmware update with visible recovery progress and confirmed installed build ID. Do not modify recovery partition to simulate progress.

- Automatic audio output: new default Auto (legacy headphone default migrates to Auto; explicit Bluetooth/USB preference preserved). Prefer detected wired headphones, otherwise the selected connected Bluetooth A2DP route. Stop and reap the previous decoder before reopening the same track at the latest reported second. Paused audio never auto-starts; removal without a valid alternative retains position for explicit Play. Clear extended-volume consent during route changes. USB remains unavailable until verified; no new Bluetooth pairing stack. Host tests exercise route decisions and stop command; physical route switching, latency, and A2DP readiness need device validation.
- Paused seeking retains the desired position without automatically starting audio. Audio route checks use a 500 ms deadline while a playback child exists; no idle polling daemon.

- Battery and playback follow-up: clock formatting runs on a monotonic deadline rather than every player report; identical position/duration reports do not redraw the screen. Periodic library refresh is spaced to 90 seconds (180 with saver). SD removal is checked during playback even with Smart Sleep active; no sleeping remount is started. Volume changes during decoder teardown no longer cancel a queued route transition. Device power savings are not measured.
