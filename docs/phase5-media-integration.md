The owner confirmed native FLAC from /mnt/sd_0/Music/vals-plantas.flac, and the imported original MIPS FFmpeg 7.1.5 artifact independently matched the reported SHA-256. The SD copy matched after replacement and was remounted ro,nosuid,nodev,noexec. Decoder size 3,570,684 bytes. 10 seconds of FLAC decoded in 1.02 seconds; RAM available after decoding was 38 MiB. MP3 was absent, not physically tested.

The cumulative source contains independent audio and software Smart Sleep permissions, route initialization using mixer numid=8 value 2, exact ALSA hw:0,0 for 48 kHz S16_LE stereo, headphone-gated play/pause, physical volume events, and no kernel suspend operations. Other WAV formats retain the unverified plughw conversion path. DAC volume and mute are deliberately not written. Hardware output is capped at the physical test's software gain (3 percent squared = 0.0009 at UI 100%); uncapped decoding for offline use is unchanged. This is intentionally a quiet development test, not a calibrated listening-volume range. UI volume is a percentage of that cap. Real power-button, display, unplug and volume behavior still need testing on the device.

Startup attempts decoder ensure only when an independently provisioned trusted pin exists. SD stays noexec and read-only. Loader verifies a protected RAM snapshot, checks the native version before replacing a cache, and fails nonfatally to WAV-only. CPU and file size limits constrain the version probe; no wall-clock timeout is available in the previous rootfs. Existing valid RAM snapshots are reused. This creates only three independent markers, no executable in flash. Do not activate broad features or kernel suspend.
