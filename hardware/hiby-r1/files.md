# Phase 3C — PocketOS File Manager

Native framebuffer microSD browser, five visible list entries with scroll controls, 160-item/4096-entry per-directory scan cap, folders first. Browse only the mounted /mnt/sd_0, with descriptor-relative traversal, no symlinks, no dot paths and no crossing devices. No file manager access to internal system storage. Open indexed audio under Music in Now Playing; open indexed books under Books in reader. Other locations/formats are not registered for opening. Current playback must be stopped before selecting a different audio file.

Writes require --allow-file-writes; default read-only. Writes restricted to regular files beneath Music, Books, Documents, Downloads, Pictures and Videos. No update or OS directories, no hidden files, no overwrite, no recursive directory operation, no shell command. Copy/move clipboard then navigate to destination, More > Paste Here, Confirm. Rename has a compact ASCII lowercase keyboard, erase and clear. Delete is permanent and confirmed. Copy/move/rename use an 8 KiB buffer, 64 MiB transfer limit, at least 1 MiB remaining free space; copy then file fsync then source unlink for moves/rename. Not atomic as a move; unexpected power loss can leave the source plus partial destination, and a failed unlink leaves a completed copy. No directory fsync or cryptographic copy verification. Transfer blocks UI while copying; no background worker currently. Companion metadata/book sidecar files are not automatically moved. Hidden/long and non-ASCII names may not display/edit fully. Folder creation, directory rename/move/delete, large-file transfer and device filesystem behavior are pending.

Fixture tests copy, refuse overwrite, rename and delete, reject symlink traversal and protected update directory; host CI renders FILES preview. Actual hardware not verified. No foundation rebuild or firmware package.

## Phase 6 — On-demand Wireless File Transfer (development)

On-device: Settings > Wireless > Wireless File Transfer > START TRANSFER. On success the R1 displays its local Wi-Fi HTTP address (port 8765) and an eight-digit session-only pairing code. Open that address from a browser on the same Wi-Fi, enter the code, and upload or download. Press STOP TRANSFER when finished. The process exits after 15 minutes without connections and is terminated when the shell exits. No transfer-server process is started when the feature is off.

Storage is restricted to the existing Music, Books, Documents, and Downloads folders directly beneath a verified mounted /mnt/sd_0. This never writes the rootfs, firmware, or update staging. Uploads have a 512 MiB file limit, 16 MiB SD reserve, a 120-byte printable-ASCII filename limit, and no overwrite. Writes stream through an 8 KiB buffer using a new file descriptor opened without following symlinks. Interrupted writes are removed on graceful termination. Downloads reject symlinks and nonregular files. A maximum of 128 files are listed per folder. Folder deletion and arbitrary filesystem browsing are not supported.

The server binds to wlan0's IPv4 address, checks the requested HTTP Host, uses a per-session eight-digit header code, has no cross-origin API permissions, and exits after five incorrect code attempts. No executable payloads are run, and the PIN is kept in process memory only. However this uses **unencrypted HTTP**. Restrict it to a trusted local network, never expose or forward TCP port 8765 to the Internet, and avoid sending sensitive files until TLS is implemented.

The trusted PocketOS development launcher enables the manually activated UI action, not the server itself. Host integration tests run against a localhost-only fixture server with synthetic SD folders; that fixture option is omitted from production binaries. Real R1 MIPS ABI, Wi-Fi networking, FAT behavior, memory and battery measurements, and safe release packaging are not verified. Do not flash unverified application artifacts.

The server does not consume process RAM when disabled; while active it serves one connection at a time and streams in bounded buffers. Benchmarks on the R1 are required before claiming a fixed RAM footprint.
