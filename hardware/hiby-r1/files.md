# Phase 3C — PocketOS File Manager

Native framebuffer microSD browser, five visible list entries with scroll controls, 160-item/4096-entry per-directory scan cap, folders first. Browse only the mounted /mnt/sd_0, with descriptor-relative traversal, no symlinks, no dot paths and no crossing devices. No file manager access to internal system storage. Open indexed audio under Music in Now Playing; open indexed books under Books in reader. Other locations/formats are not registered for opening. Current playback must be stopped before selecting a different audio file.

Writes require --allow-file-writes; default read-only. Writes restricted to regular files beneath Music, Books, Documents, Downloads, Pictures and Videos. No update or OS directories, no hidden files, no overwrite, no recursive directory operation, no shell command. Copy/move clipboard then navigate to destination, More > Paste Here, Confirm. Rename has a compact ASCII lowercase keyboard, erase and clear. Delete is permanent and confirmed. Copy/move/rename use an 8 KiB buffer, 64 MiB transfer limit, at least 1 MiB remaining free space; copy then file fsync then source unlink for moves/rename. Not atomic as a move; unexpected power loss can leave the source plus partial destination, and a failed unlink leaves a completed copy. No directory fsync or cryptographic copy verification. Transfer blocks UI while copying; no background worker currently. Companion metadata/book sidecar files are not automatically moved. Hidden/long and non-ASCII names may not display/edit fully. Folder creation, directory rename/move/delete, large-file transfer and device filesystem behavior are pending.

Fixture tests copy, refuse overwrite, rename and delete, reject symlink traversal and protected update directory; host CI renders FILES preview. Actual hardware not verified. No foundation rebuild or firmware package.
