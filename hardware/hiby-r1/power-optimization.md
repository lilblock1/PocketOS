# Phase 4A — idle and memory optimization
Both Phase 3G checks passed. Shell sampling now has an independent monotonic deadline (60s regular / 120s saver) and no longer starves during playback. Music uses the existing progress pipe in poll rather than unconditional one-second wake timer; timer fallback is used only after closure until child reaped. Redraws suppressed during opt-in idle dim or screen-off; UI state and music continue. Paused playback uses a five-second fallback timeout instead of 500ms polling; commands wake it immediately. No hardware suspend during playback, or otherwise. Pressure telemetry reads MemTotal/MemAvailable and shell RSS; these are not actual R1 measurements. Optional custom reader atlas (18,240 bytes) allocated only when needed, freed on book close or change. Native font retained.

Flags: --allow-backlight plus --allow-idle-dim permits idle dim at 60s standard / 25s saver, reader 180s / 90s. --allow-screen-off separately permits zero backlight at 120s / 60s (reader 300s / 180s). Only the unique discovered backlight and real sysfs attributes are used, restore exact saved brightness on input or normal teardown, consume initial wake gesture, no dim during active update/radio requests. If wake is not delivered by the same device, blank may not be recoverable without reboot, so screen-off stays opt-in until hardware test. No voltage, clock limit, charger or suspend writes.

--allow-cpu-policy: optional single existing sysfs cpufreq policy, only change performance to advertised schedutil or ondemand when saver enabled; skip missing/ambiguous/other governor. Restore original on saver disable or normal exit if still owned. No per-track governor changes; actual driver and performance are unverified. Radio scans remain on demand, no rfkill or automatic disconnect. Cache/microSD scanning unchanged; no unverified memory pressure kill or forced suspend. Power screen includes saver toggle and telemetry. Host tests policy timing, governor allowlist, locks; no hardware writes in CI. No foundation rebuild or flash.
